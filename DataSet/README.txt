=======================================================
               DATASET MOVIELENS
=======================================================

Os arquivos .csv que contém os dados dos filmes e 
avaliações devem ser colocados nesta pasta.

O sistema espera encontrar os seguintes arquivos:
 - movies.csv
 - ratings.csv
 - tags.csv

Estes arquivos não são enviados para o GitHub devido
ao seu tamanho. O arquivo .gitignore já os ignora
automaticamente.

Caso queira usar os arquivos em outro lugar do seu PC,
basta configurar a variável DATASET_PATH no arquivo .env
na raiz do projeto (use o .env.example como modelo).
